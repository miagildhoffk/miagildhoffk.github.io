04 · Selected Work

Projects

Syddansk Universitet · Master's Thesis · Vejle Municipality IT Department
Predicting Indoor Climate with IoT and Machine Learning
IoT sensor data · DMI weather API · Python · SQL

Worked on Vejle Municipality's challenges around indoor climate quality. The goal was to predict when the indoor climate would start to deteriorate, so staff could act proactively before it became a problem.

Collected and processed data from IoT sensors, retrieved the underlying records with SQL, cleaned it, and analysed it in Python to investigate which factors affected indoor climate. Weather data from DMI was integrated into the model via their API, and the result was delivered as both a prediction model and a concrete alert designed for the people who would use it.

  • Collected and processed data from IoT sensors
  • Used SQL to retrieve the underlying data
  • Cleaned the data before analysis
  • Analysed the data in Python
  • Investigated which factors affected indoor climate
  • Integrated weather data from DMI (the Danish Meteorological Institute) via their API into the model
  • Developed a machine learning model to predict when indoor climate conditions would deteriorate
  • Designed a figure together with an accompanying message to be sent to employees before the indoor climate became too poor, giving them time to air out the room
  • Took the project from an organisational challenge to a technical solution proposal
